## 4. Core Achievements (Technical)

*   **Failed Token Extraction Evasion (Anti-Infinite Loop)**
    *   **What changed:** Re-architected `tools/comeet/harvest_tokens.js` to modify the in-memory failure objects and construct explicit `$set: { enabled: false, error: '...' }` `bulkWrite` injections into MongoDB instead of silently dropping the bad iterations.
    *   **Why:** Hallucinated or broken `careers_page_url` values from Perplexity discovery were leading to 404s. The script previously ignored them on DB upsert, which caused them to remain stuck as `enabled: true` with no token, forcing identical Puppeteer failures on every future harvester run.
    *   **Where:** `tools/comeet/harvest_tokens.js` (Extraction loop & `injectToMongoDB` bulk array builder).

*   **Identified Strict ATS Injection Paths**
    *   **What changed:** Proven that `tools/inject_and_validate.js` is strictly a Workday/Greenhouse HTTP validation tool and cannot handle Comeet's token ecosystem. The handoff mandates direct execution of the local `harvest_tokens.js` script to process the discovery JSON.
    *   **Why:** `inject_and_validate.js` uses simple `axios` calls that trigger 404s on modern Comeet architectures needing complex headless runtime evaluation for `window.COMPANY_DATA`.

*   **Proactive Production Calibration & Purge CLI**
    *   **What changed:** Authored `tools/run_proactive_calibration.js` offering a two-stage runtime workflow (Safe Reporting natively, Purging strictly with `--confirm`). It handles missing `createdAt` attributes via an advanced `$or: [ { createdAt: { $lte: reportCutoffTime } }, { createdAt: { $exists: false } } ]` filter. 
    *   **Why:** To establish a local analysis sandbox that explicitly interacts with production MongoDB without relying on the cloud-orchestrator volume/time triggers, thereby circumventing Atlas's strict 512MB limits.
    *   **Where:** `tools/run_proactive_calibration.js` and `package.json` CLI scripts (`calibrate:report` / `calibrate:purge`).

## 7. Observability & Maintenance

*   **To run the Unified Orchestrator isolating ATS paths:**
    *   Command: `$env:SKIP_LINKEDIN="true"; node ats/orchestrator.js`
*   **To safely evaluate Calibration & Database Health (Dry Run):**
    *   Command: `npm run calibrate:report` (Outputs MD to `docs/analyze/` and outputs total prospective deletion counts).
*   **To actively Purge Calibration DB & Update Triggers:**
    *   Command: `npm run calibrate:purge` (Requires `--confirm` internally; completely wipes old data in production).
*   **To run the Complete Handoff for newly discovered Comeet leads:**
    *   Command: `node tools/comeet/harvest_tokens.js` (Does not require `inject_and_validate.js`).
*   **Known Failure Modes:**
    *   If Comeet scraping continues looping dead queries, ensure the MongoDB records for those IDs correctly reflect `enabled: false`.
